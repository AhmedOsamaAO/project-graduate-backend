# Triage labels

| Role                | GitHub label    | Meaning                             |
| ------------------- | --------------- | ----------------------------------- |
| Needs evaluation    | needs-triage    | Maintainer must evaluate            |
| Needs clarification | needs-info      | Waiting for information             |
| Agent-ready         | ready-for-agent | Fully specified for autonomous work |
| Human-ready         | ready-for-human | Requires human implementation       |
| Declined            | wontfix         | Will not be actioned                |

Wayfinding maps and decision tickets carry only `wayfinder:*` labels; do not apply implementation-triage labels to them.
